# Disclosure Boundary

This repository is intentionally limited to public-safe engineering documentation and diagrams.

## Excluded material

The showcase excludes:

- client names, personal identities, and private correspondence;
- contract, payment, proposal, or commercial details;
- account numbers, brokerage identifiers, and trading-account information;
- API keys, tokens, passwords, private keys, and other credentials;
- private repository URLs and private infrastructure details;
- proprietary implementation notebooks or source code;
- raw, licensed, or confidential market datasets;
- serialized models and model artifacts from the private delivery;
- generated private reports, screenshots, logs, and handover packages;
- private Git history or commit ancestry from the engineering repository.

## Included material

The showcase may include:

- sanitized problem framing;
- conceptual architecture;
- data-validation methodology;
- chronological model-validation approach;
- high-level feature families;
- zone/regime research concepts;
- deterministic testing methodology;
- repository-governance and security lessons;
- limitations and non-claims.

## Independence

This public repository has independent Git history. It is not a mirror, fork, filtered export, or copied history of the confidential engineering repository.
