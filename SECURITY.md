# Security Policy

This repository is a sanitized public case study and should never contain confidential client-delivery material.

## Reporting

If you discover a credential, private key, personal information, confidential dataset, private implementation detail, or another disclosure issue in this repository, do not reproduce the sensitive value in a public issue or pull request.

Use GitHub's private vulnerability-reporting/security-advisory mechanism when available, or notify the repository owner through an existing private channel.

## Repository boundary

Do not add:

- passwords, tokens, API keys, or private keys;
- personal or client-identifying information;
- account identifiers or commercial details;
- private datasets or serialized delivery models;
- proprietary implementation notebooks/source;
- private repository URLs, logs, screenshots, or conversations.

All contributions must pass the public-safety workflow before merge.
